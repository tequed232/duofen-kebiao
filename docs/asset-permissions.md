# 素材授权台账（Asset Permissions）

> 目的：任何第三方素材在进入本仓库之前，必须在这里留下**授权记录**。
> 没有记录的素材一律不得进入 `web/`、`app/` 或任何构建产物。
> 背景：早期版本曾未经授权使用他人插画（见 README 致歉声明），此后按本表流程执行。

## 流程

1. **发私信**：复制下面「私信模板」，附上仓库链接与截图，发给作者。
2. **等待回复**：把作者的回复原文（文字或截图路径）填进本表「作者回复原文」。
3. **判定**：
   - 同意 → 把状态改为 `approved`，填写署名方式与范围，然后才可以把文件放进 `web/public/`（或 `app/src/main/res/`）。
   - 拒绝 / 未回复 → 状态保持 `declined` / `pending`，**素材不得进入仓库**。
4. **引入后**：在「关于 → 致谢」与 README 里按约定署名，并在本表登记文件路径与提交哈希。
