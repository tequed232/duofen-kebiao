## 一、一句话定位

**多分课表**是一个用 Material 3 Expressive 语言重做的手机课表应用：四日课表 + 教材识别 + 上课提醒，
**界面材质是"液态玻璃"**，数据全部留在本机、不联网上传。

- 形态：竖屏手机应用（安卓 APK + 网页版同一份构建）
- 设计基准：**412 × 892 dp**，实测设备 1080 × 2800（3.1×）
- 技术观感关键词：液态玻璃（透镜折射 / 边缘色散 / 边界散射）、弹簧物理、系统级触感反馈
- 受众：大学生本人 + 同学；投放场景：B 站 / 抖音 / 酷安 / GitHub README 顶部 / 项目主页

## 二、创作要点（宣传片必须传达的三件事）

### 1. 记忆点①：底栏是"真的玻璃"，能直接透出课表
底栏不是半透明色块，而是**把背后的内容掰弯**的透镜：内容穿过底栏边缘时
①被**折射**（形变）、②边缘出现**色散**（极细的蓝橙色边）、③边界处**散射**（内容"化"开）。
前情提要：这一版之前它只是一块模糊的磨砂，这版才做到"看得清列表 + 看得出玻璃"。
> 画面要求：一定要有**内容滚动穿过底栏**的镜头（课表卡片/列表行从底栏下面穿过去），这是全片最重要的一个镜头。

### 2. 记忆点②：一切都有物理感与触感
- 底栏色块**跟手 + 流体拉伸**（离中心越远越拉长），撞到两端**先被压扁再弹回**
- 加速度驱动形变：甩得越快越"扁长"，手指一停自己收回原状
- **触感反馈**（真机震动）：撞墙 / 切换标签 / 点课程 / 步进周数 / 回到今天（最重档）
> 画面要求：不能只是"划一下"，要拍出**按压—形变—回弹**的连续过程；可加轻微运镜强调弹性。

### 3. 记忆点③：转场与返回都从"中间弹出"
所有页面切换统一为**从画面正中放大弹出**（新页放大、旧页放大淡出），不再整屏横移；
安卓 14+ 支持**可预测式返回**：手指往回拖时，上一屏按手势进度从中间长出来。
> 画面要求：给一个完整的"进入二级页 → 手指拖回 → 松手弹回"的镜头。

### 4. 其他值得入镜的功能
| 功能 | 卖点 |
| --- | --- |
| 四日课表 | 上午/中午/下午/晚上时间轴，左右拖动跟手翻页，点课程看老师/教室/周次 |
| 教材识别 | 拍/选教材封面 → 走自配的图片识别接口 → 自动匹配课程并标记要带的书 |
| 上课提醒 | 提前 N 分钟提醒，通知上直接「导航去 / 我到了」；安卓 16 状态栏**实况（灵动岛 / 流体云）** |
| 一键回到今天 | 右下角常驻 FAB（单手拇指够得到），触发最重一档触感 |
| 导入自己的课表 | `.doc/.rtf`、HTML 表格、CSV、粘贴文本都能导入，数据只存本机 |
| 开源与致谢 | 应用内「关于」有完整设计说明与致谢名片墙；开源依赖清单逐条列出 |

## 三、视觉规范（必须一致，别自创）

| 项 | 值 / 规则 |
| --- | --- |
| 应用图标 | 作者提供的插画（蓝发角色，深蓝夜空底 `#13161F`）。**严禁裁切、调色、加特效、二次生成** |
| 主色 | 跟随系统强调色；系统没给时用备用 Green 主题（种子 `#00391C`） |
| 字体 | Roboto（中文走系统字体），不要换字体 |
| 形状 | Material 3 Expressive：按钮胶囊、卡片 20dp、对话框 28dp、底栏同心 34dp 圆角 |
| 深浅色 | 深色 / 浅色两套都要出现（深色更能体现玻璃） |
| 手机壳 | 竖屏直角满屏；不要加刘海/挖孔贴图、不要加品牌 Logo 水印 |

## 四、宣传片规格

| 项 | 要求 |
| --- | --- |
| 主片时长 | **30 秒**（另出 15 秒竖版剪辑） |
| 画幅 | 主片 16:9（1920×1080）；竖版 9:16（1080×1920） |
| 帧率 | 60 fps（玻璃材质与弹簧动效在 60fps 才不糊） |
| 屏幕内容 | 直接用真机/浏览器录屏，**不要用 AI 生成的假 UI**（假 UI 一眼假，且与实机不符） |
| 允许的 AI 生成部分 | 背景氛围、光效、转场包裹、片头片尾字（不得覆盖或改写屏幕内容） |
| 字幕 | 简体中文，字号大、贴底居中，单行不超过 14 字 |
| 配乐 | 轻电子 / Lofi，节奏与"弹出、回弹"对齐；不要人声歌曲 |
| 输出 | MP4（H.264, 15 Mbps 以上）+ 封面图 1 张（1280×720） |

## 五、30 秒分镜脚本

| # | 时长 | 画面 | 屏幕上发生什么 | 字幕 |
| --- | --- | --- | --- | --- |
| 1 | 0:00–0:03 | 冷启动，Logo 弹入 | 启动页：插画图标 + 「多分课表」+ 加载指示 | 多分课表 |
| 2 | 0:03–0:07 | 课表页正面 | 四日课表：上午/中午/下午/晚上，今天那一列高亮 | 四天课表，一眼看完 |
| 3 | 0:07–0:12 | **镜头贴到底栏**（重点） | 内容滚动穿过玻璃底栏：边缘折射 + 色散 + 散射，列表文字仍看得清 | 玻璃是真的玻璃——能透过去看清列表 |
| 4 | 0:12–0:16 | 手指按在底栏拖动 | 色块跟手拉伸 → 撞到左端**压扁** → 松手弹回切页 | 跟手、撞墙、回弹，还有震动 |
| 5 | 0:16–0:20 | 点开一门课 | 中间弹出二级页：老师 / 节次 / 教室 / 上课日期；点地点唤起地图 | 点一下，老师教室周次全出来 |
| 6 | 0:20–0:24 | 教材识别 | 选教材封面 → 识别中 → 自动匹配课程并标记要带的书 | 拍一下封面，认出是哪本书 |
| 7 | 0:24–0:27 | 状态栏特写（安卓 16） | 实况通知（灵动岛 / 流体云）倒计时「10 分钟后 · 高等数学 · 3-402」 | 上课前自动提醒，还能一键导航 |
| 8 | 0:27–0:30 | 回到课表 + 片尾 | 点右下角「回到今天」→ 页面中间弹出回到今天；片尾字 | 数据只存本机 · 开源 · v3.0.2 |

竖版 15 秒：保留 **3、4、6** 三个镜头（玻璃穿透 → 拖动回弹 → 教材识别），片头片尾各 2 秒。

## 七、授权与禁止项（务必遵守）

**必须**
1. 应用图标插画为本项目作者作品：**整幅等比显示，禁止裁切、调色、加特效、风格迁移或再次生成**。
2. 出现课表数据时，**教师姓名必须打码 / 替换为占位名**（真实姓名属个人信息，不对外展示）。
3. 片尾标注：`多分课表 v3.0.2 · 开源 · github.com/tequed232/duofen-kebiao`。

**禁止**
1. 使用任何第三方插画、字体、音乐素材（音乐请用可商用授权曲库并附授权说明）。
2. 把 UI 做成"概念图"或改动配色/圆角/字体（与实机不符会造成预期落差）。
3. 宣称"AI 生成的美术资源"或暗示图标/插画是 AI 作品。
4. 展示联网上传、账号登录等本项目**不存在**的能力。
